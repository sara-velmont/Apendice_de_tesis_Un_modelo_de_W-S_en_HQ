
# Un modelo de Watts-Strogatz para hipergrafos químicos

Este repositorio contiene el código fuente, simulación y análisis de datos utilizados para la generación de resultados de la tesis de maestría:

> **"Un modelo de Watts-Strogatz para hipergrafos químicos"**  
> **Autora:** Sara Nayely Vélez Montesinos  

---

## 📌 Contenido del repositorio
- `/src` o scripts principales para la generación de la red / hipergrafo.
- Archivos de simulación para las métricas del modelo Watts-Strogatz.
- Scripts para el procesamiento y graficación de resultados.
